<step name="preflight_gate">
**Check for pre-flight completion before proceeding.**

**Skip if `plan_count` from init JSON is 0** — no plans means nothing to gate. Skip this step entirely.
(Consistent with session-gate/SKILL.md:295 which skips Check 20 when no PLAN files exist.)

**Parse `--skip-preflight` from $ARGUMENTS:**
- If `--skip-preflight` is present but `--reason` is missing or empty:
  ```
  Error: --skip-preflight requires --reason "description".
  Example: /gsd:execute-phase 4 --skip-preflight --reason "doc-only gap closure"
  ```
  Stop execution.
- If `--skip-preflight --reason "..."` is present with a non-empty reason:
  - Log to console: `[PREFLIGHT OVERRIDE] Reason: {reason}`
  - Set `PREFLIGHT_SKIPPED=true` and `PREFLIGHT_SKIP_REASON="{reason}"` for later logging in SUMMARY.md
  - Skip the rest of this step

Look for `*-PREFLIGHT.md` in `${PHASE_DIR}`:
```bash
PREFLIGHT_FILE=$(ls -t "${PHASE_DIR}"/*-PREFLIGHT.md 2>/dev/null | head -1)
```

Also check `.planning/milestones/` paths: if `${PHASE_DIR}` is under `.planning/phases/`, also look in `.planning/milestones/*/` for the same phase number pattern. Use whichever path contains the PREFLIGHT file (per D-09, ENFC-05).

**If no PREFLIGHT file found:**
```
Execution blocked: Phase ${PHASE_NUMBER} has PLAN.md but no PREFLIGHT.md.
Run: /pre-flight
Then re-run: /gsd:execute-phase ${PHASE_NUMBER}
```
Stop execution (do NOT proceed to discover_and_group_plans).

**If PREFLIGHT file found**, read the most recent one (by `ls -t`) and grep for the verdict line:
- Extract the line matching `Verdict:` (or `## Verdict`)

**If verdict grep returns empty (no Verdict line found):**
```
Execution blocked: Phase ${PHASE_NUMBER} PREFLIGHT.md found but contains no Verdict line — file may be incomplete.
Re-run: /pre-flight
Then re-run: /gsd:execute-phase ${PHASE_NUMBER}
```
Stop execution. (Fail closed — malformed PREFLIGHT must not silently pass.)

**If verdict contains `NO-GO`:**
```
Execution blocked: Phase ${PHASE_NUMBER} latest PREFLIGHT verdict is NO-GO.
Fix the required changes, then re-run: /pre-flight
Then re-run: /gsd:execute-phase ${PHASE_NUMBER}
```
Stop execution.

**If verdict contains `CONDITIONAL GO`:**
```
Phase ${PHASE_NUMBER} PREFLIGHT verdict is CONDITIONAL GO.
The following MEDIUM findings were noted:

{List MEDIUM findings from the PREFLIGHT file}

Proceed with execution? (yes/no)
```
Wait for explicit user confirmation. If user says no, stop execution.

**If verdict contains `GO` (not `NO-GO`, not `CONDITIONAL GO`):**
Proceed silently to `discover_and_group_plans`.

**Gap-closure phases** (decimal numbers like 4.1): follow the same gate logic. They do not inherit the parent phase's PREFLIGHT — they either have their own PREFLIGHT or must use `--skip-preflight --reason`.

# Mirrors CARL RULE_9 in .carl/project-template
</step>
```
